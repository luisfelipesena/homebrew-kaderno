# Kaderno for Mac

Install the signed and notarized app with Homebrew:

```sh
brew install --cask luisfelipesena/kaderno/kaderno
```

Requires Apple Silicon and macOS 15 or later.

You can create a separate local notebook without a Kaderno account. Cloud sign-in and private device pairing are optional. Creating a local notebook does not import existing cloud content or another memory store.

This repository holds the download recipe and Sparkle update feed. Application source is maintained separately.

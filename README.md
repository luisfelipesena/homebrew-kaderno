# Kaderno for Mac

Signed and notarized macOS releases and the Homebrew cask for Kaderno.

The application source remains in its private development repository. This repository contains distribution metadata and release artifacts only.

## Installation

Once a release is published:

```sh
brew install --cask luisfelipesena/kaderno/kaderno
```

Kaderno checks for signed updates through Sparkle. Your notebook and pending edits are stored separately from the application bundle.
